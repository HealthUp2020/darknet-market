# Animation — card hover & select (tactile), Everdell-style

Prepend the shared spec from [00-everdell-motion.md](00-everdell-motion.md), then this prompt.

```
[MOTION LANGUAGE] + Animate the tactile HOVER and SELECT states for a NIGHT MARKET card. Hover:
the card gently lifts (~6px) with a soft growing shadow and a faint accent glow, easing in ~180ms.
Select: it settles into a raised, steadily-glowing state with a small cyan ring and a subtle
"picked up" tilt; deselect eases back down. Valid-to-act cards BREATHE with a slow soft glow so the
player can see what is interactive. Show 3–4 NIGHT MARKET cards — one hovered, one selected, one
idle-breathing — plus a note on the disabled (dimmed, no glow) state.
```
