# Operator avatars — salvage machines (shared spec + 4 variants)

Paste the SHARED SPEC, then ONE variant block, per generation (four assets total).

```
SHARED SPEC — NIGHT MARKET operator avatar
A front-facing portrait bust of a scrappy bipedal "machine lifeform" (NieR:Automata reference):
a rounded, riveted salvage-metal HEAD as the focal point, two glowing round OPTIC eyes, weathered
rusted-steel plating with bolts/seams/scuffs, thin articulated neck/shoulders, a hint of upper
torso. Junkyard-robot character — a little forlorn, a little menacing.
- FRAMING: square, centered, head + shoulders (avatar/chip crop). Fills ~80% of the frame.
- BACKGROUND: transparent (or a flat dark disc #141a24 if a backdrop is needed). No scene.
- LIGHT: soft top-front key + a subtle rim light in the optic colour. Matte body, NO glossy plastic.
- PALETTE (NIGHT MARKET tech-noir): body = desaturated gunmetal / rusted steel (#3a4048, #5a5048,
  rust #7a4a2e). The ONLY neon is the glowing OPTICS (the rare-tier accent) + a faint matching rim.
- STYLE: clean vector-friendly shapes, readable at 40–64px (avoid fine noise that muddies when
  small). Consistent head silhouette + framing ACROSS all four so they read as a set; vary the
  optic colour, wear, and build so the four are instantly tellable apart.
- DELIVERABLE: square, transparent, self-contained SVG preferred (tintable) else transparent PNG.
```
